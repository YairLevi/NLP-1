# Part B — Unigrams: answers and explanations

All numbers come from [`results.md`](results.md). That file is generated by
the scripts in this folder and holds the full tables (top 50, rank table,
frequency table, examples).

## How the numbers were produced

```bash
cd B/unigrams
python count.py ../../ass1/english.txt out/english   # ~6.5 min
python count.py ../../ass1/hebrew.txt  out/hebrew    # ~5 min
python analyze.py                                    # writes results.md
```

| File | Role |
|------|------|
| `tokenizer.py` | the token definition (below), and streaming the file in 64 MB blocks |
| `count.py` | pass 1 counts all tokens (gives N); pass 2 counts only the first N/2 tokens. It writes `out/<lang>.counts.tsv`, `out/<lang>.half.tsv` and `out/<lang>.meta.json`. |
| `analyze.py` | reads the count files and answers Q1–Q7 into `results.md` |

The data files are read in place from `ass1/` and are never copied.
`out/` (the ~60 MB of count files) is git-ignored. Re-running `count.py`
recreates it.

### Token definition

A token is a maximal run of characters that are neither whitespace nor
punctuation. Punctuation is stripped from the edges of each
whitespace-separated chunk and kept inside it (`ice-cream`, `U.S`, `צה"ל`).
The assignment's example gives exactly
`they ate apples and then they ate some ice-cream`.

- **Punctuation** = all Unicode categories P\* (punctuation) and S\* (symbols:
  `= + $ |` …), plus control characters. A chunk made only of these (`!!`,
  `=`, `—`) yields no token.
- **Invisible format characters** (category Cf: right-to-left marks,
  zero-width spaces) are deleted first. They are common in Hebrew text and
  would otherwise create types that look identical to real ones.
- **Hebrew niqqud** (vowel marks, category Mn) is *not* punctuation and stays
  part of the token.
- **Case is kept** (`The` ≠ `the`), following the definition literally.
  Lowercasing would cut English types from 868,633 to 782,100 (−10%). It
  would not change Hebrew, which has no case.
- **Numbers count as tokens** (`2011`, `1.56`): they contain no whitespace or
  punctuation.

## Q1–Q3: tokens, types and the tokens/types ratio

| | English | Hebrew |
|---|---:|---:|
| tokens | 84,467,357 | 63,554,884 |
| types | 868,633 | 1,624,707 |
| tokens / types | **97.2** | **39.1** |

**Why is the Hebrew ratio so much lower?** Hebrew has fewer tokens but almost
twice as many types, so each type repeats far less often. The main reasons:

1. **Prefixes are attached to the word.** The Hebrew words for "the", "and",
   "in", "to", "from", "that" and "as" are single letters (ה ו ב ל מ ש כ),
   written as part of the next word. One English type "house" corresponds to
   many Hebrew types:

   | type | count |
   |---|---:|
   | בית ("house") | 85,476 |
   | בבית ("in the house") | 40,061 |
   | לבית ("to the house") | 14,939 |
   | הבית ("the house") | 14,235 |
   | מהבית ("from the house") | 703 |
   | שבבית ("that is in the house") | 283 |
   | והבית ("and the house") | 201 |

   In English these are two separate tokens each, and the function word
   ("the", "in" …) is counted under one very frequent type. **35% of all
   Hebrew types** (570,024) are a prefix letter + another existing type.
2. **Richer morphology.** Hebrew marks gender, number and person on verbs,
   nouns and adjectives, and attaches possessive and object pronoun suffixes
   (ביתו "his house", ראיתיו "I saw him"). English uses separate words
   instead ("his", "him"), which again pile up on a few frequent types.
3. **Spelling variation.** Hebrew has *full* and *defective* spelling (with or
   without the letters ו and י used as vowels), plus optional niqqud: 69,026
   types contain niqqud marks. The same word therefore appears in several
   written forms.
4. **The English corpus is also bigger** (84M vs 64M tokens). The ratio grows
   with corpus size, because tokens keep growing linearly while new types
   slow down. But size alone does not explain a gap of 2.5×.

So in Hebrew, one "word" carries what English spreads over several tokens.
This means fewer tokens, more distinct types, and a lower ratio.

## Q4: first half vs. the whole file

| | English | Hebrew |
|---|---:|---:|
| types in the first half | 582,501 | 1,021,628 |
| types added by the second half | 286,132 (+49%) | 603,079 (+59%) |
| new types appearing > 2 times in the second half | 38,039 | 53,637 |
| new types appearing > 5 times | 10,991 | 12,224 |
| new types appearing > 10 times | 3,815 | 3,444 |

Examples (full lists in `results.md`):

| | English | Hebrew |
|---|---|---|
| > 10 times | `Quenya` (185), `Coatbridge` (167), `WinFS` (161), `Vithoba` (156), `D'Oliveira` (138) | `מדיקר` (182), `פאראלימפיות` (161), `ג'ינדאל` (160), `אהרנפרייז` (105) |
| 6–10 times | `Aalborg's` (10), `Ahwahnee` (10), `Al-Birwa` (10) | `א-סיידה` (10), `אאלפוולד` (10), `אבן-פארוח` (10) |
| 3–5 times | `AECOM` (5), `APROSOMA` (5), `ACA's` (5) | `א-דוויש` (5), `א-נאסר` (5), `א-רקה` (5) |

**Explanation.**

- **The vocabulary never stops growing** (Heaps' law: types ≈ k·N^β, with
  β < 1). Doubling the text added another ~50% types, not ~0%. Most new
  types are rare: names, numbers, typos, foreign words, and (in Hebrew) new
  prefix+word combinations.
- **New types appearing more than 10 times in the second half are almost
  all topic-specific names**: Quenya (Tolkien's Elvish language), Coatbridge
  (a Scottish town), WinFS (a Microsoft file system), the Paralympics in
  Hebrew. The corpus is a collection of encyclopedia-like articles. A name
  that is central to one article appears many times in that article and
  nowhere else, so its occurrences cluster ("burstiness"). If the article
  happens to be in the second half, the type is missing from the first half
  entirely. Word occurrences are **not** spread evenly through a text.
- **Hebrew adds proportionally more types** (+59% vs +49%), for the reasons
  in Q1–Q3. A familiar word can still show up as a *new* type with a prefix
  combination not seen before (`ב-"מסע`, "in 'Journey").

## Q5: the top 50 types

Full table in `results.md`. The top 10:

| | English | Hebrew |
|---|---|---|
| 1–5 | the, of, and, to, in | של (of), את (accusative marker), על (on), הוא (he/is), עם (with) |
| 6–10 | a, was, The, on, that | בשנת (in the year), היה (was), גם (also), היא (she/is), לא (not) |

**Similar:** both lists are almost entirely **function words**:
prepositions, pronouns, conjunctions, auxiliaries and "was/were" forms. That
is universal. Function words are needed in nearly every sentence regardless
of topic, so in every language they make up the top of the list (Zipf's
law).

**Different:**

- **English has "the", "a", "and", "in", "to" … at the very top; Hebrew does
  not.** Hebrew attaches ה (the), ו (and), ב (in), ל (to) and מ (from) to the
  next word, so they never become tokens of their own. Their frequency is
  spread over prefixed types (Q1–Q3). Hebrew's top is instead led by the
  function words that *are* separate words: של, את, על.
- **Hebrew has את**, the definite-object marker, which has no English
  equivalent.
- **Case splits English types:** `The`, `In`, `He`, `It` are separate entries
  next to `the`, `in`, `he`, `it` (sentence-initial capitals). Hebrew has no
  case.
- **Content words enter the Hebrew list earlier:** בשנת (in the year,
  rank 6), ישראל (Israel), בית (house), העיר (the city), הברית (the
  covenant / "United" in ארצות הברית, the United States). Since the
  strongest function words are hidden inside prefixes, content words move
  up. The topics also show through: an Israeli encyclopedia mentions Israel
  and the US constantly, and "in the year" dates every event.

## Q6: the 100th, 1,000th and 10,000th most frequent types

| rank | English | count | Hebrew | count |
|---:|---|---:|---|---:|
| 100 | can | 58,309 | אלה (these) | 36,240 |
| 1,000 | something | 9,217 | דוגמה (example) | 6,965 |
| 10,000 | Achievement | 724 | ההיסטוריונים (the historians) | 865 |

Rank 100 is still a function word in both languages. Rank 1,000 is a common
general word. By rank 10,000 the words are specific, and the Hebrew one
already carries a prefix and a plural suffix (ה+היסטוריון+ים). Frequency
falls roughly in proportion to 1/rank: from rank 100 to 10,000, counts drop
by about 80× in English and 42× in Hebrew. Hebrew's curve is flatter
because its frequency is spread over more types.

## Q7: frequency of frequencies

| number of types that appear | English | Hebrew |
|---|---:|---:|
| exactly once | 418,325 | 878,438 |
| exactly twice | 121,062 | 211,992 |
| exactly 3 times | 58,446 | 99,594 |
| exactly 5 times | 25,000 | 41,608 |
| 10 times or more | 153,349 | 241,626 |
| 100 times or more | 38,418 | 54,646 |
| 1,000 times or more | 7,913 | 8,740 |
| 10,000 times or more | 901 | 641 |

**Explanation.**

- **Zipf's law / long tail:** a few types are extremely frequent, and the
  vast majority are rare. **Types that appear only once (hapax legomena)
  are about half the vocabulary**: 48% of English types and 54% of Hebrew
  types. Yet together they are under 1.5% of the tokens.
- **The counts fall off like a power law:** going from 1 to 2 occurrences
  divides the number of types by 3.5 (English) or 4.1 (Hebrew), and from 2
  to 3 by about 2. A rare
  word is far more likely to be seen once than twice.
- **Hebrew has more rare types but fewer very frequent ones** (641 vs 901
  types with ≥ 10,000 occurrences). Same cause as before: prefixes and
  inflection split one "word" into many types, which inflates the tail and
  drains the head.
- **Practical consequence:** however large the corpus, a new text will
  contain words never seen before. A fixed word vocabulary cannot cover a
  language. This motivates the sub-word (BPE) units in the next part of the
  assignment.
